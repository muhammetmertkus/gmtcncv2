# Tabler Icons

The SVG files in this directory are from Tabler Icons v3.35.0:
https://github.com/tabler/tabler-icons/tree/v3.35.0/icons/outline

They are distributed under the MIT license in `LICENSE`. They are used without
modifying the files; the renderer substitutes `currentColor` at runtime so the
same assets can be tinted to match the panel state.
